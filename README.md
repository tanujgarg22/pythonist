# Dictionary Labs

This project contains Python exercises for practicing dictionaries and list operations.

## Topics Covered

- Creating dictionaries from two lists
- Using `zip()`
- Using `enumerate()`
- Iterating through lists with a `for` loop
- Assigning dictionary keys and values
- Printing dictionary contents

keys = [1, 2, 3, 4, 5]
